# Earth Papertrails · 地球折纸足迹

An interactive 3D origami pop-up book and miniature papercraft world for collecting and journaling your real-world travel footprints.

## Three-Stage Interactive Experience

1. **Study Bookshelf (书房正面书架)** — Sunlit walnut bookcase displaying themed travel albums (*East Asia*, *Europe*, *Wild Earth*, *Island Coast*) plus **+ New Footprint Book** creator, interactive paper globe, rubber stamps, and origami desk lamp.
2. **90° Accordion Pop-Up Book (立体折纸翻页书)** — Rigid-origami V-fold floor gussets and fanned accordion guard pages on both sides, with layered die-cut scenes that fold and unfold smoothly as you flip pages.
3. **Miniature Paper World & Postcard Journal (微缩漫游与足迹收集)** — Walkable open-book diorama with a lantern-bearing paper traveller, day/night lantern light pools, collectible pressed keepsake scraps, Polaroid photo upload, ink-stamped postcards, and JSON Passport export/import.

## Local Development

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Visual Inspiration

- Cardstock fibre shading, die-cut cream rims, warm contact AO, tilt-shift DoF, and paper foley inspired by [xikhar/papertrails](https://github.com/xikhar/papertrails).
